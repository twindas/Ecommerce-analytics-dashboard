# E-Commerce Sales Analytics Dashboard

A modern and responsive **E-Commerce Sales Analytics Dashboard** built to visualize sales, revenue, orders, customers, and other business insights through an interactive dashboard interface.

## 🛠️ Technologies Used

**TypeScript (React TSX)** → Frontend UI Components & Logic
**TypeScript (Node/Express)** → Backend Server (`server.ts`)
**HTML** → Base HTML Structure (`index.html`)
**CSS / Tailwind CSS** → Styling & Theme Layouts
**JSON** → Configuration & Data

## ✨ Features

* 📊 Interactive sales analytics dashboard
* 💰 Revenue and sales overview
* 🛒 Order and customer insights
* 📈 Data visualization and analytics
* 🎨 Modern and responsive UI
* 📱 Mobile-friendly design
* ⚡ Fast React-based frontend
* 🔧 Node/Express backend integration

## 🚀 Run Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd E-Commerce-Sales-Analytics-Dashboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.
